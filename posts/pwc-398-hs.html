Task 1: Divisible Average

import           Control.Exception (assert, evaluate)



mean :: [Int] -> Int

mean [] = 0

mean xs = sum xs `div` length xs



solve :: [Int] -> Int

solve =  mean . filter (\\x -> even x && x `mod` 3 == 0)
We define the integer mean of N integers as the sum of the numbers divided by the amount of numbers. In Haskell, the div operator performs integer division, contrary to the standard (\/\/) operator. After that, we can just filter the input list of numbers for those that are even and divisible by 3 and apply the mean to them.

Task 2: String Difference

import           Control.Exception (assert, evaluate)

import           Data.Char         (ord)

import           Data.Function     (on)

import           Data.List         (groupBy, sortOn)

import           Data.Ord          (comparing)



diff :: String -> [Int]

diff xs =

  let xs\' = map ord xs

  in map (uncurry $ flip (-)) $ zip xs\' (tail xs\')



solve :: [String] -> String

solve xs

  = head

  . map (fst . head)

  . filter ((==) 1 . length)

  . groupBy (\\(_, ys) (_, zs) -> ys == zs)

  . sortOn snd

  $ zip xs (map diff xs)

Now this is some Haskell brainfuckery if you are not used to the syntax.

The diff function computes the ASCII code for each character in the input string and then returns the adjacent difference of the resulting array. Haskell functions are curried, which means every function is a one-argument function. If a function takes two arguments, that really means you have a one-argument function that returns a function taking an argument. What uncurry does it make it so that functions behave as in other programming languages and accept a tuple instead of a list of arguments, which perfectly fits our purpose here.

The pipeline in solve needs to be read backwards. We first zip the original list of strings with the differences, because we are going to need the original string as the answer. Then, we sort the list of differences in order to be able to group them and then filter those lists consisting of a single element. That\'s the element we want, so we just pick it using an unorthodox combination of fsts and heads.
